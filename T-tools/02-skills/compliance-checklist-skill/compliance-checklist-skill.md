# Skill: Compliance Checklist

> Creates regulatory compliance checklists that make complex requirements actionable and trackable.

## Trigger Words
"compliance", "regulatory", "audit checklist", "compliance check", "regulation requirements"

## Format

```markdown
# Compliance Checklist: [Regulation/Standard]

**Date:** [Date]
**Type:** Compliance Checklist
**Regulation:** [Full name and version]
**Applicable to:** [Which parts of the business]
**Assessment date:** [Date]
**Assessor:** [Name]
**Next audit:** [Date]

---

## Overview

**Regulation summary:** [2-3 sentences: what this regulation requires, in plain language]
**Key deadline:** [If applicable]
```

## Quality Checks

- [ ] Requirements map to specific regulation sections
- [ ] Evidence is specific (not "we have a policy")
- [ ] Gaps have owners and deadlines
- [ ] Priority reflects actual risk, not just effort
- [ ] Checklist is auditor-friendly (an auditor could verify each line)

---

## Top-1% Knowledge

What separates a great practitioner of this format from an average one. Use these as the quality bar.

- **Risk-based prioritization.** Not all items are equal. Tier by likelihood × impact. Spend time accordingly.
- **Evidence-first design.** For each item, what's the evidence? If you can't document it, you can't prove it.
- **Control vs Test split.** Controls are what you do. Tests are how you verify. Both belong in the checklist.
- **The Exception Handling Path.** What happens when a control fails. Pre-define escalation.
- **Continuous vs Periodic.** Some controls run continuously (logging). Others periodically (access review). The checklist must reflect cadence.

---

## Common Mistakes to Avoid

The predictable failure modes for this format. Check against these before shipping.

- Box-checking. The form is filled. The risk is still there.
- Missing exceptions. Policy says X, practice is Y. Auditors find this fast.
- No owner per item. Distributed responsibility = no responsibility.
- Static checklist. Regulations change. The checklist doesn't get updated. Drift accumulates.
- No mitigation when an item fails. Identifying a gap without a treatment plan is theater.
