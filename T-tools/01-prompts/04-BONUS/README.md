# 05-BONUS

> 11 advanced prompts for ongoing use AFTER the workshop, plus 7 department-specific tracks for B2B users.
> If you're looking for the workshop's deep-dive prompts (create new agent, enhance agent, create skill, enhance skill, create workflow), those live in `T-tools/01-prompts/04-deep-dive/`.

---

## What Lives Here

### 1. Bonus Prompts (the numbered files `05-` through `15-`)

These are advanced prompts that apply to ANY track. Use them when you've outgrown the basics and want to push the system further.

| # | Prompt | Use When |
|---|--------|----------|
| 05 | Train Agent on Document | You have a 50-page doc and want an agent fluent in it |
| 06 | Clone Voice from Conversation | You want to capture someone's tone from a transcript |
| 07 | Enable Auto-Revision Loop | You want outputs that self-improve before showing you |
| 08 | Connect API Keys | You need an agent to use external services |
| 09 | Content Calendar | You want a scheduled content plan |
| 10 | Repurpose Content | One source, many outputs |
| 11 | Analyze Competitor | Market intelligence on a specific competitor |
| 12 | Create Hook Bank | Reusable opening lines for content |
| 13 | Weekly Review | Structured reflection on what shipped |
| 14 | Audit My System | The system audits itself |
| 15 | Client Onboarding Flow | Service-business onboarding pipeline |

### 2. Deluxe Department Tracks (`_deluxe/` subfolder)

Department-specific 4-step prompt sequences for B2B users: HR, Finance, Legal, Product, Management, Support, Customer Success.

If you're using the system in a company context, **start there.**

See `_deluxe/README.md` for the department menu.

## When to Use Which

| Your Goal | Use |
|-----------|-----|
| Build a custom agent for a specific need | `T-tools/01-prompts/04-deep-dive/01-create-new-agent.md` |
| Enhance an existing agent with deep research | `T-tools/01-prompts/04-deep-dive/02-enhance-agent-with-research.md` |
| Codify a recurring output as a skill | `T-tools/01-prompts/04-deep-dive/03-create-new-skill.md` |
| Enhance an existing skill with deep research | `T-tools/01-prompts/04-deep-dive/04-enhance-skill-with-research.md` |
| Codify a multi-step process as a workflow | `T-tools/01-prompts/04-deep-dive/05-create-new-workflow.md` |
| Create one output for your department role | `05-BONUS/_deluxe/[your-dept]/03-create-output.md` |
| Set up a content calendar | `05-BONUS/09-content-calendar.md` |
| Audit your whole system | `05-BONUS/14-audit-my-system.md` |
